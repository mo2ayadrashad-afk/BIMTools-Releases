# BIM Tools Prototype (By Moayad Habib)

Revit add-in: three **BIM Tools** ribbon tabs (Model, Design, Docs & Data) for Revit 2023 - 2027.

## ⬇ Download
**[Latest version](../../releases/latest)** → download `BIMTools-Prototype-Setup-v….exe` from *Assets*.

## Install (2 minutes, no admin rights)
1. Close all Revit sessions.
2. Run the Setup. It finds the Revit versions on your PC and installs for each one (only for your Windows user).
   - Windows may show **"Windows protected your PC"** because the Setup isn't code-signed yet:
     click **More info → Run anyway**.
3. Start Revit. At the add-in security prompt choose **Always Load**.
4. Sign up once (name, email, company, mobile). The tools switch on after approval - you get an email.

## Requirements
- Revit 2023, 2024, 2025 (update 2025.5+), 2026 (update 2026.5+) or 2027.
- Internet for sign-up; after approval the tools also work offline for 14 days.

## Update
When a new version is out, Revit's **About** button shows *Update available* and you get an email.
Run the new Setup - it replaces the old one.

## Uninstall
Windows **Settings → Apps → Installed apps → BIM Tools Prototype → Uninstall**.
Your settings in `%AppData%\BIMToolsPrototype` are kept.

## Other downloads
`BIMTools-Prototype-v….zip` is the same add-in with `Install.cmd` - for PCs that block `.exe` files.
